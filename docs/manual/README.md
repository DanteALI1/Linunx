# Ручная настройка сервера — оглавление

Этот раздел — **поэтапная ручная настройка** без опоры на «просто запусти apply-*.sh».
Скрипты из репозитория остаются справочными эталонами; здесь каждая команда разобрана:
что делает, зачем, какой ожидаемый результат, как проверить.

| Документ | Содержание |
|----------|------------|
| [01-how-it-works.md](01-how-it-works.md) | Как устроены слои СЗИ и роли (теория + примеры) |
| [02-redos8-manual.md](02-redos8-manual.md) | РЕД ОС 8 — полная ручная настройка (этапы 0–12) |
| [03-astra18-manual.md](03-astra18-manual.md) | Astra Linux SE 1.8 — полная ручная настройка |
| [04-wazuh-manual.md](04-wazuh-manual.md) | Ручной прогон Wazuh Agent: upload→install→sudoedit→тесты |

Объём: каждая команда сопровождается блоками **зачем**, **как работает**, **проверка**.

Рекомендуемый порядок чтения/работы:

1. Прочитать **how-it-works** (чтобы понимать, *почему* так).
2. Выполнить ручную настройку своей ОС (**02** или **03**).
3. Пройти **04** (Wazuh) как приёмочный сценарий.
4. Сверить с автотестами `tests/TEST-MATRIX.md`.

> Скрипты `apply-redos.sh` / `apply-astra.sh` делают то же самое автоматизированно.
> Для обучения и аудита конфигурации используйте ручной путь из этого раздела.
