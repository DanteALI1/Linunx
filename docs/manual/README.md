# Ручная настройка сервера — оглавление

Этот раздел — **поэтапная ручная настройка** без опоры на «просто запусти apply-*.sh».
Скрипты из репозитория остаются справочными эталонами; здесь каждая команда разобрана:
что делает, зачем, какой ожидаемый результат, как проверить, **из-под какой УЗ**.

| Документ | Содержание |
|----------|------------|
| [01-how-it-works.md](01-how-it-works.md) | Как устроены слои СЗИ и роли (теория + примеры) |
| [02-redos8-manual.md](02-redos8-manual.md) | РЕД ОС 8 — полная ручная настройка (этапы 0–12, поле **УЗ:**) |
| [03-astra18-manual.md](03-astra18-manual.md) | Astra Linux SE 1.8 — полная ручная настройка |
| [04-wazuh-manual.md](04-wazuh-manual.md) | Ручной прогон Wazuh Agent: upload→install→sudoedit→тесты |
| [05-who-runs-what.md](05-who-runs-what.md) | **Матрица: этап → учётная запись** |
| [06-auditd-rules-catalog.md](06-auditd-rules-catalog.md) | **Все правила auditd + ключи + зачем (CIS/STIG/RBAC/практики)** |

Объём: каждая команда сопровождается блоками **УЗ**, **зачем**, **как работает**, **проверка**.
